# 架构与边界

本仓库是迁移包的清单层，不是补丁层。根清单固定了上游提交和正式发布参照；模块目录只保存描述性元数据，不保存代码、二进制、密钥或可执行应用逻辑。

未来由第三方执行方在**独立且可丢弃的工作副本**中，按以下三方边界工作：上游工作副本提供输入，本迁移包只提供经审查的候选描述，顾砚进行人工集成与验收。小云是任何正式发布的批准方。执行方不得把本仓库当作可直接应用的补丁来源。

流程只能生成集成候选：先运行只读预检，再由顾砚选择单一模块、核实实际调用路径并手工制作候选变更。发现合并冲突、基线不符、敏感文件或不明确依赖时立即停止；不自动解决冲突，不写入目标，更不自动部署。

`shadow` 是明确的实验性研究目录，不属于当前正式功能，也不应进入正式集成候选，除非未来另有小云批准和独立设计审查。
